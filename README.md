# wei-chih-accounts
這是一款簡約、易用的個人 資產追蹤 網頁，讓使用者自行命名並管理新臺幣、美元、人民幣、日圓與黃金資產。透過記錄資產增減、換算新臺幣總值，以及查看資產分配與歷史變化圖表，快速掌握自己的財務狀況。  網站支援外幣參考匯率更新、手動設定匯率與黃金價格，並提供瀏覽器本機儲存及 JSON 資料備份功能。採用單一 HTML 檔案製作，整合 CSS 與 JavaScript，無須註冊帳號即可操作。  本作品透過與 AI 討論規格、產生程式及逐步修改的 Vibe Coding 流程開發，作為課程作業與個人資產管理工具原型。資產估值僅供參考，不構成投資建議；目前不支援跨裝置同步。
